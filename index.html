Install guide安装教程

Up and running in two minutes两分钟装好

  1. Download the Windows installer above and open it.在上面下载 Windows 安装版，双击打开。
  2. If "Windows protected your PC" appears, click More info → Run anyway. Lumora isn't signed with a paid certificate, so Windows asks first.如果跳出 「Windows 已保护你的电脑」，点 「更多信息」→「仍要运行」。Lumora 没有付费签名证书，所以 Windows 会先问一下。
  3. Follow the installer, then open Lumora from the Start menu.按安装程序的步骤走，装好后从「开始」菜单打开 Lumora。
Portable ZIP: unzip anywhere and open Lumora.exe inside the Lumora folder.免安装版：解压到任意位置，打开 Lumora 文件夹里的 Lumora.exe。
  1. On your phone, download the APK above.用手机在上面下载 APK。
  2. Open it. Android asks to allow installs from this source — turn it on for your browser, then go back.打开下载好的文件。安卓会问要不要 允许安装未知来源的应用，帮你的浏览器打开这个选项，再返回。
  3. Tap Install, then Open.按 安装，装好后按 打开。
Play Protect may warn about an unknown app. Tap More details → Install anyway.Play 保护机制可能会警告「未知应用」，按 「详细信息」→「仍然安装」 就行。
  1. On the TV, install Downloader (by AFTVnews) from the Play Store.在电视的 Play 商店安装 Downloader（AFTVnews 出品）。
  2. In Downloader, enter jting904.github.io/Lumora, scroll to Download and pick the Android APK.在 Downloader 里输入 jting904.github.io/Lumora，滑到「下载」，选安卓 APK。
  3. Allow Downloader to install apps when asked, then install and open Lumora. Everything works with the remote.系统询问时允许 Downloader 安装应用，装好就能打开 Lumora。全程用遥控器就能操作。

The iPhone version isn't out yet. When it is, this page will walk you through installing it step by step.iPhone 版还没推出。推出后，这里会一步一步教你怎么安装。

FAQ

Questions常见问题

Is Lumora free?Lumora 要钱吗？

Yes. No subscription, no ads in the app.不用。没有订阅，app 里也没有广告。

I didn't get the confirmation email.我没收到确认信。

Check spam or junk — school and work mailboxes often file it there. The sender is Lumora. The link opens a page saying your email is confirmed; then sign in inside the app.看看垃圾邮件 —— 学校和公司的邮箱常常把它放在那里。寄件人是 Lumora。点链接后会看到「邮箱已确认」的页面，然后回 app 登录就行。

I forgot my password.忘记密码怎么办？

On the sign-in page, enter your email and tap "Forgot password?". We email a code; type it into Lumora on any device and choose a new password.在登录页填邮箱，按「忘记密码？」。我们会寄一个验证码，在任何一台设备的 Lumora 里输入，就能设新密码。

Do my history and list carry over to a new device?换新设备，记录和收藏还在吗？

Yes. Sign in with the same account and your Continue Watching and My List come along.在。用同一个帐号登录，继续观看和收藏都会跟过来。

Windows says the app might be unsafe.Windows 说这个 app 可能不安全？

That's SmartScreen showing for apps without a paid certificate. Click "More info → Run anyway". Every release ships with signed checksums, and the app's updater only installs releases that match them.那是 SmartScreen 对没有付费证书的 app 的提示，点「更多信息 → 仍要运行」即可。每个版本都附有签名的校验码，app 自动更新只会安装对得上的版本。

How do updates work?怎么更新？

Lumora checks for new versions and asks before installing. You can also download the latest version from this page anytime.Lumora 会自己检查新版本，安装前会先问你。你也可以随时在这个页面下载最新版。

Is it open source?是开源的吗？

Yes, under GPL-3.0, built on ZPlay. The code is on GitHub.是，以 GPL-3.0 发布，基于 ZPlay。代码在 GitHub 上。
